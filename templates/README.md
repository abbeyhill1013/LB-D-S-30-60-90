# templates/

Client-facing and internal templates used across every engagement, regardless
of pattern. Where a pattern defines *what* the work is, these define *how it's
communicated*.

Planned contents:

- `sow-guardrails.md` — standard scope/assumption/exclusion language for SOWs,
  keyed to pattern and band
- `mobilization-packet.md` — the sales-to-delivery handoff artifact. No
  packet, no provisioning.
- `status-report.md` — the weekly/biweekly status format (see Tool #1 in
  `tools/`)
- `closeout-memo.md` — end-of-engagement memo, including expansion signal
  capture (see Tool #4 in `tools/`)
- `qbr-pack.md` — Tier A quarterly business review format (see Tool #5 in
  `tools/`)

See `TRACKER.md` in the repo root for current build status.
