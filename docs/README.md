plan. This is the narrative layer — the "why" behind the templates, patterns,
and tooling in the rest of the repo.

Planned contents:

- `org-design.md` — horizons (Forward/Present/Deep), role split, headcount
  plan across the first 12 months
- `tiering.md` — Tier A/B/C definitions, the 3/7/5 distribution logic, and
  what changes at each tier (cadence, QBRs, escalation path)
- `rollout-plan.md` — the sequencing behind `TRACKER.md`, in narrative form
- `margin-watch.md` — the 70/70 rule: definition, thresholds, escalation
  path when an engagement trips it

See `TRACKER.md` in the repo root for current build status.
